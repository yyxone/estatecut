# Source provenance

The first public release is a clean export of the reusable `talkcut` and `propcut` workflows from a locally maintained Estatecut project. Its local Git baseline dates to June 22, 2026. The source was exported from a working tree based on commit `6b7678c302735a49d9b311b74ffb90895cc3d17a`, including then-uncommitted maintenance changes, and subsequently adapted for independent packaging.

Local development history, operational records, customer media, personal configurations, databases, and runtime assets are not published. This public repository starts with the export; its initial commit date does not represent the beginning of local development, and local commit activity is not evidence of external open-source adoption.

Public-release adaptations include bundled default resources, configurable ASR execution and timeouts, portable LUT/font lookup, independent installation checks, synthetic regression tests, and CPU-only CI. Algorithmic influences and retained notices are listed in [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md).

This release makes no claim of external users, package downloads, community contributors, or prior public maintenance. Validation covers synthetic workflows; actual ASR and real-media quality require separate evaluation.
